# Kalilur Rahman A R — Portfolio

React + Vite + TypeScript + Tailwind CSS v4 + Motion.

## Commands
```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # typecheck + production build to dist/
npm run preview
```

## Before deploying
1. Put your resume at `public/resume/Kalilur-Rahman-Resume.pdf`.
2. GitHub: create `.env` with `VITE_GITHUB_URL=https://github.com/<you>` (links stay hidden until set).
3. Testimonials: add genuine entries to `src/data/testimonials.ts`.

## Content
All content lives in `src/data/*.ts`.

## Deploy
- Netlify: build command `npm run build`, publish directory `dist`.
- Vercel: framework preset "Vite" (same build/output).
